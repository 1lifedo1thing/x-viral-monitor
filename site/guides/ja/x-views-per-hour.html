使い方ガイド

投稿の1時間あたりの表示回数：拡散の速さを読む

X は投稿が何回表示されたかを示しますが、その表示回数がどれほど速く増えているかは直接示しません。この速さが、今伸び始めている投稿と、先週すでにピークを迎えた投稿を見分ける手掛かりになります。

累計表示回数と1時間あたりの表示回数

投稿の下に表示される数字は累計で、増え続けます。今朝公開されて50,000回表示された投稿と、1か月前に公開されて50,000回表示された投稿は、数字だけを見ると同じです。しかし、前者は拡散中で、後者は数週間前に伸びが止まっているかもしれません。

公開からの経過時間で割ると、この違いを捉えられます。

1時間あたりの表示回数 = 累計表示回数 ÷ 公開からの経過時間（時間）

累計表示回数が同じでも、次のような違いがあります。

  • 12,000回表示、3時間前に公開：4,000回/時間。まだ勢いがあります。
  • 12,000回表示、4日前（96時間前）に公開：125回/時間。勢いは落ちています。

これは公開からの平均値であり、リアルタイムの速度計ではありません。最初の1時間だけ急激に伸び、その後止まった投稿も、しばらくは高い平均値を保ちます。数字と公開時刻を一緒に確認すると、誤解を避けやすくなります。

X の表示回数は何を数えているのか

X は表示回数を、投稿が閲覧された回数と説明しています。ユニーク読者数ではなく、接触回数を表す数字です。同じ人が2回見れば、2回として数えられることもあります。それでも公開されている拡散範囲の重要な指標であり、誰に対しても同じ数字なので、投稿の比較に役立ちます。

X が2022年末に表示回数を導入する前の投稿には、この数字がありません。そのため速度を計算できず、流速バッジも表示されません。

1時間に何回表示されればバズなのか

X に公式な定義はありません。分野、言語、投稿者の元々の読者数によって基準は変わります。使いやすい目安として、X Viral Monitor は次の初期値を採用しています。

バッジ1時間あたりの表示回数段階
🌱 緑1,000未満通常
🚀 オレンジ1,000〜9,999上昇中
🔥 赤10,000以上バズ

規模の目安として、1時間に1,000回のペースが1日続けば約24,000回表示されます。10,000回/時間なら1日で240,000回を超えます。X の多くの場面では、後者が一般にバズと呼ばれる状態です。

両方のしきい値を変更できます。拡張のポップアップでバッジのしきい値設定を開き、🚀 上昇中と 🔥 バズの値を変えてください。小さな分野なら300と3,000などの値が合う場合もあります。バズのしきい値は、常に上昇中のしきい値より高く保たれます。

各投稿で1時間あたりの表示回数を見る

  1. Chrome Web Store または Edge Add-ons から X Viral Monitor をインストールします。
  2. いつもどおり x.com を開きます。追加のログインや API キーは不要です。
  3. 表示回数がある投稿の操作ボタン付近に、🚀 4.2k/h のようなバッジが現れます。
  4. バッジにカーソルを合わせると、表示、いいね、リポスト、返信、ブックマーク、公開時刻、0〜100のバズスコアを確認できます。

ポップアップでは、色付きのピル型バッジと、シンプルな行内表示を選べます。数字は、投稿の読み込み時に X がブラウザーへ送っているデータから取得します。拡張に解析 SDK はなく、閲覧行動を外部へ送信しません。

バッジを一つずつ探す代わりに、ページ内の投稿を速度順に並べたい場合はランキングを有効にします。詳しくは伸び始めた投稿の見つけ方をご覧ください。

数字の読み方

  • 速度と投稿の経過時間を組み合わせる。公開40分の 🚀 投稿はまだ上昇中かもしれません。公開20時間の 🚀 投稿は長く勢いを保っていますが、返信欄はすでに混み合っている可能性があります。
  • 速度だけで判断しない。ツールチップのバズスコアは、流速40%、反応率25%、リポスト対いいね比20%、ブックマーク対いいね比15%で計算します。速度が控えめでもスコアが高ければ、流し読みだけでなく保存や共有につながっている場合があります。
  • 早めに参加する。公開直後の数時間に内容のある返信をすると、翌日に同じ返信をするより多くの人に届きやすくなります。草稿が必要ならAI 返信生成を利用できます。

よくある質問

1時間あたりの表示回数は X の公式指標ですか？

いいえ。X が公開する累計表示回数と公開時刻から、誰でも計算できます。拡張はその計算を各投稿について自動で行います。

流速を見るには X Premium が必要ですか？

不要です。投稿の表示回数は公開されており、無料アカウントでもバッジを利用できます。Premium の違いはPremium なしで見られる分析データで解説しています。

バズの基準を変更できますか？

はい。初期値は上昇中が1,000回/時間、バズが10,000回/時間です。どちらも拡張のポップアップで変更できます。
