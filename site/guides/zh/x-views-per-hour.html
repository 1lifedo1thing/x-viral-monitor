推文每小时浏览量：一条推文究竟传播得有多快

X 会显示推文被浏览了多少次，却不直接告诉你这些浏览量增加得有多快。而传播速度，能帮助你判断一条推文是在此刻开始起量，还是上周就已经过了高峰。

累计浏览量与每小时浏览量

X 推文下方的浏览量是累计值，只会不断增加。今天早上发布、获得 50,000 次浏览的推文，与一个月前发布、同样有 50,000 次浏览的推文，数字看起来完全相同，但前者可能正在快速传播，后者可能早已停止增长。

每小时浏览量通过除以发布时长，补上了这个区别：

每小时浏览量 = 累计浏览量 ÷ 发布以来经过的小时数

下面两条推文的累计浏览量相同：

  • 12,000 次浏览，3 小时前发布：4,000 次浏览/小时，仍在传播。
  • 12,000 次浏览，4 天（96 小时）前发布：125 次浏览/小时，热度已明显降低。

请记住，这个数字是发布以来的平均值，不是实时速度计。一条推文即使只在第一小时爆发，随后停滞，平均值仍可能在一段时间内保持较高。结合发布时间一起看，可以避免大多数误读。

X 的浏览量究竟统计什么

X 将浏览量定义为帖子被查看的次数。因此，它反映触达次数，不是独立读者数：同一个人看两次，也可能计入两次。它仍是判断公开传播范围的重要信号，且所有人看到的是同一个数字，适合用来比较帖子。

X 在 2022 年末引入浏览量统计之前发布的帖子，没有可用的浏览量，因此无法计算流速，也不会显示流速徽章。

每小时多少浏览量算爆款？

X 没有官方定义。爆款的标准取决于领域、语言和作者原本的受众规模。为了提供可用的参照，X Viral Monitor 默认采用以下阈值：

徽章每小时浏览量级别
🌱 绿色低于 1,000普通
🚀 橙色1,000 至 9,999升温中
🔥 红色10,000 及以上爆款

作为量级参照，一条推文若全天保持每小时 1,000 次浏览，一天约获得 24,000 次浏览；若保持每小时 10,000 次，一天会超过 240,000 次。对 X 上的大多数内容来说，后者通常就是人们所说的爆款。

两个阈值都可以调整。在扩展弹窗中打开徽章阈值设置，修改 🚀 升温和 🔥 爆款的数值。如果你关注小众领域，300 和 3,000 可能更适合你的时间线。爆款阈值始终保持高于升温阈值。

如何在每条推文旁查看流速

  1. 从 Chrome Web Store 或 Edge Add-ons 安装 X Viral Monitor。
  2. 照常打开 x.com，不需要额外登录或 API 密钥。
  3. 有浏览量的推文会在操作按钮旁显示徽章，例如 🚀 4.2k/h。
  4. 将鼠标移到徽章上，可查看浏览、点赞、转发、回复、书签、发布时间，以及 0 至 100 的爆款评分。

你可以在扩展弹窗中选择彩色胶囊或简洁行内数字两种徽章样式。数据来自 X 加载推文时已经发送给浏览器的内容。扩展没有统计 SDK，也不会向外发送你的浏览行为。

如果想直接按流速给当前页面的推文排序，而不是逐条扫徽章，可以开启热榜。具体用法见如何发现正在起量的推文。

如何读懂这个数字

  • 结合发布时间。发布 40 分钟的 🚀 推文仍可能在上升；发布 20 小时的 🚀 推文则说明热度保持了较久，同样值得关注，但回复区可能已经很拥挤。
  • 不要只看流速。提示框中的爆款评分按流速 40%、互动率 25%、转发与点赞比 20%、书签与点赞比 15% 加权。流速不高但评分较高，往往意味着读者正在收藏和分享，而不只是划过。
  • 尽早参与。推文发布前几小时留下有内容的回复，通常比一天后再回复能获得更多关注。需要草稿辅助时，可使用AI 回复生成器。

常见问题

每小时浏览量是 X 的官方指标吗？

不是。X 提供累计浏览量和发布时间，任何人都可以据此计算每小时浏览量。扩展只是为每条推文自动完成计算。

查看流速需要 X Premium 吗？

不需要。推文浏览量是公开的，免费账号也可以使用徽章。关于 Premium 增加了什么，见不用 Premium 能查看哪些分析数据。

可以自己调整爆款标准吗？

可以。默认升温阈值为每小时 1,000 次浏览，爆款阈值为 10,000 次，都能在扩展弹窗中调整。
