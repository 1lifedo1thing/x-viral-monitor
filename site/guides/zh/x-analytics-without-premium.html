使用指南

不用 X Premium，还能查看哪些分析数据？

X 将许多分析功能放到了 Premium 订阅之后，但免费账号仍能看到不少数据。而一个很有用的指标，也就是帖子浏览量增长的速度，原本就不在 X 的分析面板里。

X 经常调整各订阅档位包含的功能。本文描述写作时的情况，刻意不列容易变化的具体限额。付费前，请到 X 官方 Premium 页面核对当前功能清单。

所有账号都能看到什么

无论是否付费，每条帖子上的一些数字都是公开的：

  • 浏览量：显示在每条帖子下方。
  • 回复、转发和点赞：显示在操作栏。
  • 书签数：显示在帖子详情页。时间线里，X 不会在书签按钮旁显示数字。
  • 准确发布时间：鼠标移到时间戳上即可查看。

对于自己的帖子，免费账号通常仍能打开单条帖子的基础活动数据，移动端一般更容易找到这个入口。

Premium 增加了什么

桌面端完整的账号分析面板，包括账号层面的趋势和随时间变化的数据拆分，属于 Premium 功能。X 在 2024 年宣布为 Premium 用户扩展分析功能，此后的第三方报道也将桌面分析面板描述为 Premium 专属。

如果你专业运营账号，需要持续查看数周的粉丝增长、主页访问和链接点击，应使用这个面板或付费社交媒体工具。浏览器扩展不能替代它们。

两种版本都没有告诉你的事

无论免费还是付费，X 分析主要围绕你自己的账号。它不会告诉你别人的帖子传播得有多快。对创作者而言，另一个问题往往更有用：我的领域里，哪些帖子正在起量，我应该在哪里参与讨论？

你可以手动计算：查看浏览量，把鼠标移到时间戳上，算出经过的小时数，再相除。但对时间线里的每条帖子都这样操作并不现实。

免费查看公开推文的每小时浏览量

X Viral Monitor 在推文加载时自动完成计算。它是免费的 Chrome / Edge 扩展，免费 X 账号也能使用。

  • 流速徽章：有浏览量的推文会显示每小时浏览量徽章：🌱 低于 1,000，🚀 从 1,000 起，🔥 从 10,000 起。阈值可调整，详见推文每小时浏览量说明。
  • 悬停详情：查看浏览、点赞、转发、回复、书签、发布时间，以及综合流速、互动率、转发比和书签比的 0 至 100 爆款评分。
  • 时间线书签数：开启对应设置后，可在每个书签按钮旁显示数量。
  • 热榜：按传播速度给当前页面的推文排序，详见如何发现正在起量的推文。

这些功能适用于他人的公开帖子，也适用于你自己的帖子。扩展读取 X 加载推文时已经发送给浏览器的数据，因此不需要 API 密钥或 Premium，除了照常登录 x.com，也不需要额外连接账号。扩展没有统计或追踪像素。

明确的能力边界

  • 它只能展示 X 公开显示的数据，无法获取主页访问、链接点击或粉丝人口特征等私有指标。
  • 每小时浏览量是发布以来的平均值，不是实时速率。需要结合发布时间一起理解。
  • 没有历史趋势图，只告诉你当前页面上正在发生什么。
  • X 在 2022 年末加入浏览量之前发布的帖子没有浏览量，因此不会显示徽章。

一套实用的免费组合

对大多数个人创作者而言，免费账号加上 X 已有的单帖数据，就能覆盖基础需求。用 X Viral Monitor 补上时间线的流速和排名，再用移动端查看自己帖子的活动数据。如果之后确实需要数月的账号趋势，Premium 面板才可能更有价值。

常见问题

查看一条推文有多少浏览量，需要 X Premium 吗？

不需要。帖子的浏览量对所有人公开。

X Viral Monitor 能显示我的粉丝分析吗？

不能。它使用 X 公开显示的单帖数据：浏览、点赞、转发、回复和书签，无法访问私有账号分析。

X Viral Monitor 免费吗？

徽章、热榜和书签数免费。Pro 每月 $2.9 或每年 $29，增加隐藏低流速帖子的过滤功能。
