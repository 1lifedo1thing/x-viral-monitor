使用指南

直接在 X 回复框里使用 AI 回复生成器

多数 AI 回复工具需要把推文复制到另一个标签页，向聊天机器人提问，再把答案粘回来。X Viral Monitor 将生成器放进回复框，自动读取推文，并把最终选择留给你。

使用流程

  1. 点击任意推文的回复按钮，回复编辑器里会出现 ✦ AI 按钮。
  2. 点击按钮，选择提示词模板。
  3. 候选回复会逐条流式生成。第一条出现后就可以选择，不必等全部完成。
  4. 点击候选回复，将它填入 X 回复编辑器。按需修改，最后由你点击回复发送。

工具不会自动发帖，只生成草稿，由你决定发送什么。按钮只出现在回复框里，不出现在主发帖框里。

读取对应的上下文

扩展从 X 已经加载的数据里获取推文正文，因此不用复制粘贴原文。当你回复别人推文下面的一条评论时，提示词会同时包含原推文和你正在回复的评论，让模型理解对话，而不是只看到脱离上下文的一句话。

长帖子和 X 长文使用独立模板，因为回复一篇 2,000 词的文章，与回复一句话，需要不同的写法。

选择 AI 服务

服务需要什么文本发送到哪里
X Grok（默认）登录 X 即可，不需要 API 密钥。通过当前会话使用 X 自己的 Grok 服务
OpenAI 兼容服务：OpenAI、DeepSeek、OpenRouter、Kimi / Moonshot、Qwen / DashScope、SiliconFlow该服务的个人 API 密钥你所选择的服务商
本地模型：Ollama 或 LM Studio在电脑上运行应用，并下载模型保留在本机

使用 Grok 时，请求从浏览器通过现有 X 会话发出。默认开启的临时聊天选项，会让这些请求不进入 Grok 历史记录。可用额度取决于 X 对你的账号设置的限制。使用云端服务时，推文和回复上下文会通过你的密钥发送给该服务商。设置中的测试连接按钮可帮你提前确认配置是否正常。

把模板改成自己的

默认模板覆盖自然回复风格和几种替代写法。所有模板都可以在扩展弹窗的 AI 回复标签页编辑，也可以新增自己的模板。需要注意：

  • 推文模板和长文模板分别保存。
  • 占位符标记原推文的插入位置；如果没有写占位符，原推文会自动追加。
  • 候选数量可设为 1 至 20 条，默认 10 条。
  • 可选设置支持直接按 Enter 发送回复，不必使用 Command 或 Ctrl + Enter。

好的模板会描述你的表达方式和目的，而不只是“写一条回复”。例如：“以一名后端工程师的身份回复，补充一个具体细节或例子。不用话题标签和表情，200 字符以内。”

如何用得更好

AI 草稿是起点。有价值的回复通常会增加事实、数字、反例或个人经历。把候选回复当作供你判断的选项，而不是直接粘贴的成品。

  • 选择值得参与的帖子。尽早回复正在起量的帖子，通常比回复昨天已过高峰的帖子更容易被看见。流速徽章可以帮助区分，见如何发现正在起量的推文。
  • 发送前编辑。至少修改一个短语，让它更像你自己的表达。
  • 不要批量刷回复。短时间发布大量相似回复，对读者和 X 系统来说都像垃圾信息。这个工具用于挑选一条好草稿，而不是追求数量。

常见问题

AI 回复生成器免费吗？

是的，它属于扩展的免费功能。使用 Grok 时消耗你的 X 账号所拥有的 Grok 权限；使用其他服务时，API 用量费用由你向对应服务商支付。

它会自动发布回复吗？

不会。它只将你点击的候选内容填入回复框，由你审核并点击回复发送。

需要 API 密钥吗？

Grok 使用已登录的 X 会话，不需要密钥。选择 OpenAI 兼容服务时才需要对应密钥。通过 Ollama 或 LM Studio 使用本地模型也不需要密钥。
