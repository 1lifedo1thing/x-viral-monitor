2026 年值得了解的 X / Twitter Chrome 扩展

与其列一长串工具，不如选少数各有所长的扩展。本文介绍的工具都在 Chrome Web Store 上架，并仍在维护。按你的 X 使用方式选择即可。

关系披露：本站由 X Viral Monitor 和 X Article Markdown Paste 的开发者制作，它们是下面的前两项。另两项来自其他开发者，因使用广泛、且解决了我们扩展没有覆盖的问题而列入。我们与他们没有合作关系。

1. X Viral Monitor：发现正在起量的推文

适合：希望尽早发现传播迅速的帖子并参与讨论的创作者。

为有浏览量的推文添加每小时浏览量徽章：🌱 低于 1,000/h，🚀 从 1,000 起，🔥 从 10,000 起，阈值均可调整。悬浮热榜按流速给当前页面的推文排序。它还支持在时间线显示书签数、图片缩放和长图阅读、用本地规则过滤垃圾信息、成人内容及引流回复，通过 Grok 或自选 AI 服务生成回复草稿，以及将推文复制为 Markdown。

价格：免费。Pro 每月 $2.9 或每年 $29，提供 14 天试用，增加隐藏低流速帖子的过滤功能。代码按 MIT 协议开源。

Chrome Web Store · Edge Add-ons · 官网

2. X Article Markdown Paste：用 Markdown 写 X 长文

适合：在 Obsidian、Notion、VS Code 或 AI 聊天中用 Markdown 起草长文，再发布为 X Articles 的用户。

X 长文编辑器不直接理解 Markdown，粘贴草稿后通常需要手动修复标题、列表和代码块。这个扩展在粘贴时完成转换，保留格式，也处理图片、表格和推文嵌入。

价格：免费档覆盖基础格式转换，付费功能提供 14 天试用。

官网与安装入口

3. Control Panel for Twitter：重新掌握时间线

适合：觉得算法推荐时间线太嘈杂的用户。

它默认让你停留在按时间排序的“正在关注”时间线，而不是“为你推荐”。还提供多项设置，用来隐藏转发、引用推文、侧边栏和其他界面元素。它是开源工具，也是 Chrome Web Store 上安装量较高的 X 扩展之一。

Chrome Web Store

4. Minimal Theme for Twitter / X：更安静的界面

适合：希望 X 界面更简洁，以及需要减少干扰的写作者。

由 Typefully 团队制作。它可以隐藏推广帖子、精简导航、隐藏趋势侧栏、调整时间线宽度、隐藏指标，还能切换到只显示编辑器的写作模式。

Chrome Web Store

如何搭配

  • 账号增长：用 X Viral Monitor 找到值得回复的帖子；如果发布长文，再配合 X Article Markdown Paste。
  • 减少刷屏、提高阅读质量：选 Control Panel for Twitter 或 Minimal Theme 即可。两者功能重叠，通常不必同时安装。
  • 混合使用：整理界面的扩展可能隐藏浏览量和其他指标，与 X Viral Monitor 的用途相冲突。如果同时使用，请保留指标显示。

安装任何 X 扩展之前检查什么

  1. 权限。X 扩展应请求 x.com 的访问权限，而不是所有网站。对没有明确理由却要求读取全部浏览行为的扩展保持谨慎。
  2. 最近更新时间。X 经常改变页面结构，一年没更新的扩展可能已有部分功能失效。
  3. 开发者信息。明确的开发者、官网和支持页面是好信号。开源更方便任何人检查代码行为。
  4. 登录要求。留意索要 X 密码或要求代你发帖的扩展。上面四款都不需要你的密码。
