如何发现 X 上正在起量的推文

找到已经爆过的推文很容易。想在推文正在起量、回复还有机会被看见的时候发现它，需要关注传播速度，而不只是累计规模。

为什么常见方法更容易找到过去的热门

许多寻找爆款的建议依赖 min_faves:1000 或 min_retweets:500 等 X 搜索指令。它们有效，但筛选的是累计值。一条推文达到 1,000 次点赞时，往往已经发布数小时，热门回复的位置也基本确定，此时加入讨论的收益可能有限。

探索和趋势榜也有类似局限：它们展示话题和关键词，未必能指出你所在领域里哪些具体帖子正在加速传播。

你真正需要的是一份按浏览增长速度排序、且限定在你关心的账号和话题范围内的帖子列表。这正是 X Viral Monitor 热榜的用途。

关键指标：每小时浏览量与发布时间

X Viral Monitor 用每条推文的浏览量除以发布以来的小时数，再显示为徽章：🌱 低于每小时 1,000 次浏览，🚀 从 1,000 起，🔥 从 10,000 起。阈值可以调整，详见推文每小时浏览量说明。

刚发布不久、带有 🚀 徽章的帖子尤其值得关注：它已经显示传播潜力，却可能还没有到达高峰。

开启热榜

热榜是标题为 Hot on this page（当前页热门）的悬浮面板，默认关闭。在扩展弹窗的热榜标签页中开启即可。

  • 按每小时浏览量给当前页面已加载的推文排序，最快的排在前面。
  • 默认显示前 10 条，可在弹窗中调整数量。
  • 默认列包括排名、级别图标、简短预览、累计浏览量和流速。可以开启用户名列，也可以调整列顺序。
  • 点击一行，页面会滚动到对应推文；返回按钮可带你回到原位置。
  • 可以任意拖动面板，或开启贴边隐藏，让它收在屏幕侧边。
热榜只对 X 已在当前页面加载的推文排序，不是整个 X 的全站榜单。选对页面后，它就能成为你所在领域的局部排行榜。

在哪些页面使用

  • 领域账号列表。这通常最实用。建立一个包含 50 至 200 个重点关注账号的 X 列表，打开它，热榜就能展示这个领域的即时排序。
  • 搜索的“最新”标签页。搜索关键词，切到“最新”，再向下滚动几屏，热榜会帮你从噪声中找出正在获得关注的帖子。
  • 正在关注时间线。适合每天快速查看你的关注网络正在讨论什么。
  • 单个账号主页。可以发现这个账号的哪些近期帖子还在传播，适合研究特定账号的内容表现。

一个五分钟流程

  1. 打开领域列表或“最新”搜索结果。
  2. 向下滚动三四屏，让 X 加载足够的推文。
  3. 查看热榜。跳过一天前发布的 🔥 帖子，优先关注最近几小时发布的 🚀 和 🔥 帖子。
  4. 点开前两三条，完整阅读，判断自己是否能补充有价值的信息。
  5. 回复、引用，或先收藏留待之后处理。

隐藏没有起量的内容（Pro）

如果你希望时间线本身只展示正在传播的帖子，Pro 流速过滤可以隐藏其他内容。规则是：每分钟浏览量或累计浏览量达到你设置的阈值，就保留帖子；短推文和 X 长文可以分别设置阈值。你还可以选择作用页面：主页、列表、账号主页和推文详情页。热榜上的 Hot only（只看热门）开关也可以启用过滤。

Pro 价格为每月 $2.9 或每年 $29，提供 14 天试用。流速徽章和热榜仍然免费。

找到之后怎么做

发现传播速度之后，更重要的是如何参与。写一条能补充事实、例子或不同观点的回复。需要起始草稿时，AI 回复生成器就在回复框里。想保存帖子时，可以复制为 Markdown，将作者和原链接一起收进笔记。

常见问题

热榜展示整个 X 的爆款推文吗？

不是。它排序的是你正在查看的页面里已经加载的推文。打开列表、搜索结果或账号主页，就能对那个范围里的帖子排序。

热榜免费吗？

是的。徽章和热榜免费，只有隐藏低流速帖子的流速过滤属于 Pro。
