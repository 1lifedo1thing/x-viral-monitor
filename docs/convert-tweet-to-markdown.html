Convert a tweet to Markdown from the X share menu

Copying a tweet by selecting its text loses almost everything that makes it useful later: who wrote it, when, the link back, and the real URLs behind t.co. X Viral Monitor adds a Copy as Markdown option to the share menu that keeps all of it.

Why Markdown

Markdown is the common format for notes and docs: Obsidian, Logseq, Notion, GitHub, most static site generators and every AI chat understand it. A tweet saved as Markdown keeps its links clickable, its images visible and its source attached, whichever of those tools it ends up in.

Doing it by hand is tedious. You select the text, notice the links are t.co short links, open each one to get the real URL, copy the author and the date, and format the whole thing.

How to copy a tweet as Markdown

  1. Install X Viral Monitor for Chrome or Edge.
  2. On any tweet, click the share button (the arrow icon in the action bar).
  3. Choose Copy as Markdown at the bottom of X's share menu.
  4. Paste wherever you like. A short "Copied!" message confirms it worked.

The option is on by default. You can switch it off in the popup under other features.

What you get

A normal tweet comes out like this (example content):

Shipping the new build today. Full changelog: https://example.com/changelog

— [Jane Doe (@janedoe)](https://x.com/janedoe/status/1234567890) · 2026-09-20 14:05
  • Text as written, with line breaks kept.
  • t.co links expanded to the real destination URLs.
  • Images as Markdown image links, and videos as links, when X has sent the media data.
  • Attribution line with the display name, handle, a link to the tweet, and the post date in your local time.

Long X Articles convert too

When the tweet is an X Article, the long-form post type, Copy as Markdown pulls the full article body rather than just the preview. The article title becomes a # heading and the cover image comes first. Section headings, bold, italic, strikethrough, links, lists, quotes, code blocks and inline images follow in Markdown form. That makes it easy to archive an article, quote a section in your own writing, or hand it to an AI model for a summary.

Copy a tweet with its replies

A second share menu entry, Copy tweet and comments, copies the tweet followed by a ## Comments section. Each reply loaded on the page is numbered and formatted the same way, with its own author, link and date. Scroll down first to load more replies, since only the ones X has loaded are included. This is useful for saving a discussion, collecting feedback on a launch post, or giving an AI model the whole thread as context.

Where people use it

  • Obsidian or Logseq: paste into a daily note and the tweet is searchable and linked back to its source.
  • Research and writing: a quote with its author and date is ready to cite.
  • AI prompts: Markdown with the author and context keeps a model from guessing who said what.
  • Swipe files: save posts that took off, together with their numbers from the views-per-hour badge, and study them later.

The reverse: Markdown into X Articles

Going the other way is a different problem. The X Articles editor does not understand Markdown, so pasting a draft from Obsidian or an AI chat leaves stray # and ** marks behind. X Article Markdown Paste, a separate extension by the same developer, converts Markdown as you paste it into the Articles editor, so headings, lists, code blocks, images and tables come through formatted.

FAQ

Does converting a tweet to Markdown cost anything?

No. Copy as Markdown is part of the free version of X Viral Monitor.

Does Copy tweet and comments include the whole thread?

It includes direct replies to the tweet that are loaded on the page. Replies to replies further down a chain are left out, so for a long self-thread, copy each tweet you need separately.
