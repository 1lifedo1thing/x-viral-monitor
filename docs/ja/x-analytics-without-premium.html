X Premium なしで見られる分析データ

X の分析機能の多くは Premium 向けになりましたが、無料でも確認できる数字はまだあります。また、表示回数が増える速さという便利な指標は、そもそも X の分析画面にはありませんでした。

X は各プランの内容を頻繁に変更します。この記事は執筆時点の状況を説明し、変わりやすい具体的な上限は記載していません。支払いの前に、X 公式の Premium ページで現在の機能を確認してください。

どのアカウントでも見られる数字

有料か無料かにかかわらず、次の数字は投稿上で公開されています。

  • 表示回数：各投稿の下に表示されます。
  • 返信、リポスト、いいね：操作バーに表示されます。
  • ブックマーク数：投稿の詳細ページに表示されます。タイムラインでは、X はブックマークボタンの横に数字を出しません。
  • 正確な公開時刻：時刻の表示にカーソルを合わせると確認できます。

自分の投稿については、無料アカウントでも単一投稿の基本的なアクティビティを開ける場合が多く、モバイルアプリでは比較的見つけやすい入口です。

Premium で増える機能

デスクトップ版の完全なアカウント分析画面は Premium の機能です。アカウント単位の傾向や、時系列の内訳を確認できます。X は2024年に Premium 向け分析機能の拡充を発表し、その後の第三者の記事でもデスクトップの分析画面は Premium 専用と説明されています。

仕事としてアカウントを運用し、数週間にわたるフォロワー増加、プロフィール訪問、リンククリックを知りたい場合は、その画面や有料のソーシャルメディアツールが適しています。ブラウザー拡張は代わりにはなりません。

無料でも有料でも分からないこと

X の分析は、無料でも有料でも自分のアカウントが中心です。他の人の投稿がどれほど速く拡散しているかは分かりません。発信者には、自分の分野で今伸びている投稿は何か、どの会話に参加すればよいか、という問いの方が役立つこともあります。

表示回数と公開時刻を見て、経過時間で割れば手計算できます。ただしタイムラインの全投稿で行うのは現実的ではありません。

Premium なしで公開投稿の流速を見る

X Viral Monitor は、投稿の読み込み時にこの計算を自動で行います。Chrome と Edge 用の無料拡張で、無料 X アカウントでも利用できます。

  • 流速バッジ：表示回数がある投稿に1時間あたりの表示回数を表示します。🌱 は1,000未満、🚀 は1,000から、🔥 は10,000からです。しきい値は変更できます。詳しくは1時間あたりの表示回数の解説をご覧ください。
  • ホバー時の詳細：表示、いいね、リポスト、返信、ブックマーク、公開時刻に加え、流速、反応率、リポスト比、ブックマーク比を使った0〜100のバズスコアを表示します。
  • タイムラインのブックマーク数：設定を有効にすると、各ブックマークボタンの横に件数を表示します。
  • ランキング：現在のページの投稿を速度順に並べるフローティングパネルです。詳しくは伸び始めた投稿の見つけ方をご覧ください。

他の人の公開投稿にも自分の投稿にも使えます。投稿の読み込み時に X がブラウザーへ送る数字を読み取るので、API キーや Premium は不要です。いつもどおり x.com にログインする以外、追加のアカウント接続もありません。拡張に解析や追跡ピクセルはありません。

できることの限界

  • X が公開する数字だけを表示します。プロフィール訪問、リンククリック、フォロワー属性などの非公開指標は取得できません。
  • 1時間あたりの表示回数は公開からの平均値で、リアルタイムの速さではありません。投稿の経過時間と一緒に読んでください。
  • 過去の推移グラフはありません。閲覧中のページの状況を示します。
  • 2022年末の表示回数導入前の投稿には表示回数がないため、バッジが付きません。

実用的な無料の組み合わせ

多くの個人発信者には、無料アカウントと X の単一投稿の数字で基本的な確認ができます。X Viral Monitor でタイムライン全体の流速と順位を補い、自分の投稿のアクティビティはモバイルアプリで確認します。数か月のアカウント全体の傾向が必要になれば、Premium の分析画面を検討する段階です。

よくある質問

投稿の表示回数を見るには X Premium が必要ですか？

不要です。投稿の表示回数は誰にでも公開されています。

X Viral Monitor はフォロワー分析を表示しますか？

いいえ。X が公開する単一投稿の表示、いいね、リポスト、返信、ブックマークを使います。非公開のアカウント分析にはアクセスできません。

X Viral Monitor は無料ですか？

バッジ、ランキング、ブックマーク数は無料です。月額 $2.9 または年額 $29 の Pro では、低流速の投稿を隠すフィルターが追加されます。

X Viral Monitor をインストール

Chrome と Microsoft Edge 向けの無料拡張です。流速バッジ、ランキング、ブックマーク数、AI 返信草稿、Markdown コピーは無料です。月額 $2.9 または年額 $29 の Pro は14日間試用でき、流速フィルターを追加します。
