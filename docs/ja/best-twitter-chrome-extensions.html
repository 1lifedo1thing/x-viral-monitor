2026年の X / Twitter 向け Chrome 拡張

長い一覧ではなく、それぞれ得意分野のある少数の拡張を紹介します。いずれも Chrome Web Store に掲載され、保守が続いているツールです。X の使い方に合うものを選んでください。

1. X Viral Monitor：伸び始めた投稿を見つける

向いている人：勢いのある投稿を早く見つけ、会話に参加したい発信者。

表示回数がある各投稿に、1時間あたりの表示回数のバッジを追加します。🌱 は1,000/h未満、🚀 は1,000から、🔥 は10,000からで、すべて調整できます。フローティングランキングは現在のページの投稿を速度順に並べます。タイムラインのブックマーク数表示、画像のズームと縦長画像の閲覧、ローカルルールによるスパム・成人向け内容・誘導返信のフィルター、Grok や選んだ AI サービスによる返信草稿、Markdown コピーにも対応します。

料金：無料。Pro は月額 $2.9 または年額 $29 で、14日間の試用があり、低流速の投稿を隠すフィルターを追加します。MIT ライセンスのオープンソースです。

2. X Article Markdown Paste：Markdown で X Articles を書く

向いている人：Obsidian、Notion、VS Code、AI チャットなどで Markdown の草稿を作り、X Articles として公開する人。

X Articles のエディターは Markdown をそのまま解釈しないため、貼り付けた後に見出し、リスト、コードブロックを直す必要があります。この拡張は貼り付け時に変換し、書式を引き継ぎます。画像、表、投稿の埋め込みも扱います。

料金：無料プランは基本の書式変換に対応し、有料機能には14日間の試用があります。

3. Control Panel for Twitter：タイムラインを自分で整える

向いている人：アルゴリズムによるおすすめが騒がしいと感じる人。

初期設定では「おすすめ」ではなく、時系列の「フォロー中」タイムラインを維持します。リポスト、引用、サイドバーなどの表示を隠す多くの設定もあります。オープンソースで、Chrome Web Store の X 向け拡張の中でもインストール数が多いツールの一つです。

4. Minimal Theme for Twitter / X：落ち着いた画面にする

向いている人：X の画面をすっきりさせたい人や、集中して書ける投稿画面が欲しい人。

Typefully のチームが制作しています。広告投稿の非表示、ナビゲーションの整理、トレンドサイドバーの非表示、タイムライン幅の変更、指標の非表示ができ、エディターだけを表示するライターモードもあります。

Chrome Web Store

どう組み合わせるか

  • アカウントを伸ばす：X Viral Monitor で返信する価値のある投稿を探します。長文を公開するなら X Article Markdown Paste も組み合わせます。
  • 読む量を減らして質を上げる：Control Panel for Twitter か Minimal Theme を選びます。機能が重なるため、両方は不要な場合が多いでしょう。
  • 併用する：画面整理の拡張が表示回数などの指標を隠すと、X Viral Monitor の目的と逆になります。併用時は指標を表示したままにしてください。

X 拡張のインストール前に確認すること

  1. 権限。X 向けの拡張は x.com へのアクセスが基本です。明確な理由なく全サイトの閲覧データを求めるものには注意してください。
  2. 最終更新。X はページ構造を頻繁に変えます。1年間更新されていない拡張は、一部が動かなくなっている可能性があります。
  3. 開発者。開発者名、公式サイト、サポートページがあるかを確認します。コードを確認できるオープンソースならさらに判断しやすくなります。
  4. ログインの要求。X のパスワードや代理投稿の許可を要求する拡張には注意してください。上記4件はパスワードを必要としません。
