X の共有メニューから投稿を Markdown に変換する

投稿の文字だけを選択してコピーすると、後で役立つ投稿者、日時、元の投稿リンク、t.co の背後にある URL が失われます。X Viral Monitor の共有メニューにある Markdown コピーは、これらをまとめて残します。

Markdown を使う理由

Markdown はノートや文書で広く使われる形式です。Obsidian、Logseq、Notion、GitHub、多くの静的サイト生成ツール、AI チャットで扱えます。投稿を Markdown で保存すると、クリックできるリンク、画像、出典を保ったまま、さまざまなツールで使えます。

手作業だと、文字を選択し、t.co の短縮リンクを一つずつ開いて実際の URL を取得し、投稿者と日時をコピーして書式を整える必要があります。

コピーする手順

  1. Chrome または Edge 用の X Viral Monitor をインストールします。
  2. 投稿の操作バーにある、矢印の共有ボタンを押します。
  3. X の共有メニューの下部からMarkdown としてコピー（Copy as Markdown）を選びます。
  4. 好きな場所に貼り付けます。「コピーしました」という短い通知が出れば成功です。

この項目は初期設定で有効です。ポップアップのその他の機能設定で無効にできます。

コピーされる内容

通常の投稿は、次のような形式になります。以下はサンプルです。

今日、新しいビルドを公開します。更新履歴：https://example.com/changelog

— [Jane Doe (@janedoe)](https://x.com/janedoe/status/1234567890) · 2026-09-20 14:05
  • 本文：元の文章と改行を保持します。
  • t.co リンクの展開：実際のリンク先 URL を使います。
  • メディア：X がメディアデータを送っている場合、画像は Markdown の画像リンク、動画はリンクとして出力します。
  • 出典行：表示名、ユーザー名、元の投稿リンク、現地時間での公開日時を含みます。

X Articles も変換できる

投稿が X Article の場合、プレビューだけでなく記事の本文全体を取得します。記事タイトルは # 見出しになり、カバー画像が先頭に入ります。小見出し、太字、斜体、取り消し線、リンク、リスト、引用、コードブロック、行内画像も Markdown に変換します。記事の保存、一部の引用、AI モデルへの要約依頼に便利です。

投稿と返信をまとめてコピーする

共有メニューの投稿とコメントをコピー（Copy tweet and comments）では、投稿の後に ## Comments セクションが追加されます。ページで読み込まれた返信には番号が付き、それぞれの投稿者、リンク、日時も保持されます。コピーの前に下へスクロールして返信を読み込んでください。対象は X が読み込んだものだけです。議論の保存、公開した投稿への反応の収集、AI へ会話の文脈を渡す場合に使えます。

活用できる場面

  • Obsidian や Logseq：デイリーノートに貼れば、検索でき、元の投稿へ戻れます。
  • 調査や執筆：投稿者と日時が付いた引用を残せます。
  • AI のプロンプト：投稿者と文脈を含む Markdown により、誰の発言かをモデルに推測させずに済みます。
  • 参考資料集：伸びた投稿を流速バッジの数字と一緒に保存し、後で分析できます。

逆方向：Markdown を X Articles に取り込む

逆方向の変換は別の課題です。X Articles のエディターは Markdown を直接解釈しないため、Obsidian や AI チャットの草稿を貼ると、# や ** が残ることがあります。同じ開発者による別の拡張 X Article Markdown Paste は、貼り付け時に Markdown を変換し、見出し、リスト、コードブロック、画像、表を整えた状態で取り込みます。

一緒に使える他のツールについてはX / Twitter 向け Chrome 拡張をご覧ください。

よくある質問

投稿の Markdown 変換は有料ですか？

いいえ。Markdown コピーは X Viral Monitor の無料機能です。

投稿とコメントのコピーには会話全体が含まれますか？

ページで読み込まれた、元の投稿への直接の返信を含みます。返信への返信など、深い階層は含みません。長い連続投稿の場合は、必要な投稿を個別にコピーしてください。
