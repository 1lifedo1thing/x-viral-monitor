Best Twitter Chrome extension picks for X in 2026

A short list instead of a long one. Each extension here does one job well, is listed on the Chrome Web Store, and is still maintained. Pick the ones that match how you use X.

Disclosure: this site is made by the developer of X Viral Monitor and X Article Markdown Paste, the first two entries below. The other two are made by other developers and are included because they are widely used and do things our extensions do not. We have no relationship with them.

1. X Viral Monitor: see which tweets are taking off

Best for: creators who want to find fast-moving posts early and join the conversation.

Adds a views-per-hour badge to every tweet with a view count (🌱 under 1,000/h, 🚀 from 1,000, 🔥 from 10,000, all adjustable) and a floating leaderboard that ranks the posts on the current page by speed. It also shows bookmark counts in the timeline, improves the image viewer with zoom and long-image reading, filters spam, adult and funnel replies with locally run rules, drafts replies with Grok or your own AI provider, and copies tweets as Markdown.

Price: free. Pro ($2.9/month or $29/year, 14-day trial) adds a filter that hides slow posts. Open source under MIT.

2. X Article Markdown Paste: write X Articles in Markdown

Best for: people who draft long posts in Markdown (Obsidian, Notion, VS Code, an AI chat) and publish them as X Articles.

The X Articles editor does not understand Markdown, so pasting a draft usually leaves you fixing headings, lists and code blocks by hand. This extension converts the Markdown as you paste it, so formatting comes through, and it handles images, tables and tweet embeds too.

Price: a free tier covers the basic formatting, with a 14-day trial of the paid features.

3. Control Panel for Twitter: take back your timeline

Best for: people who find the algorithmic feed noisy.

By default it keeps you on the chronological Following timeline instead of For You, and it offers a long list of options to hide retweets, quote tweets, sidebar sections and other UI elements. It is open source and one of the most-installed X extensions on the Chrome Web Store.

Chrome Web Store

4. Minimal Theme for Twitter / X: a quieter interface

Best for: people who want X to look calmer, and writers who want a distraction-free composer.

Made by the team behind Typefully. It can remove promoted posts, trim the navigation, hide the trends sidebar, change the timeline width, hide metrics and switch to a writer mode that shows only the composer.

Which combination makes sense

  • Growing an account: X Viral Monitor to find posts worth replying to, plus X Article Markdown Paste if you publish long-form.
  • Reading less, better: Control Panel for Twitter or Minimal Theme. You probably do not need both, since they overlap.
  • Mixing them: the decluttering extensions can hide view counts and other metrics, which is the opposite of what X Viral Monitor is for. If you use both, leave metrics visible.

What to check before installing any X extension

  1. Permissions. An extension for X should ask for access to x.com, not to every site you visit. Be wary of anything that wants to read all your browsing without a clear reason.
  2. Last update. X changes its page structure often. An extension that has not been updated in a year is likely broken in places.
  3. Who makes it. A named developer, a website and a support page are good signs. Open source is better, because anyone can check what the code does.
  4. Login requests. Be careful with extensions that ask for your X password or want to post on your behalf. None of the four above need your password.
